# Sweetz

Sweetz es una plataforma moderna de venta de contenido digital desarrollada con [Next.js](https://nextjs.org). Este proyecto ofrece una experiencia visual llamativa y sensual, centrada en facilitar el acceso a contenido exclusivo mediante una interfaz estilizada y responsive.

## Requisitos previos

Antes de iniciar el entorno de desarrollo, asegúrate de tener instalado:

- [Node.js](https://nodejs.org/) v18 o superior
- [npm](https://www.npmjs.com/) (o `yarn`, `pnpm`, `bun`, según tu preferencia)
- Git

## Instalación

Primero, clona el repositorio:

```bash
git clone https://github.com/FelipeCavieresV/Sweetz.git
cd Sweetz

Instala las dependencias necesarias:

npm install

Ejecutar en modo desarrollo

npm run dev
